## Intent

The launch video for GitIsle, a free, open-source macOS app that turns the
MacBook notch into a live view of GitHub pull requests. It opens on the pain
(merging, then tabbing to GitHub to check, again and again), reveals the
island in the notch, and shows the real app doing its job: a merge going live,
banners for what matters, every PR one hover away, the board, and stats. It
closes on the logo and the GitHub link. Confident and fast, like an Apple-style
product sting: black, white, and GitHub's state colours.

The user asked for real app components, HyperFrames, and downloaded
launch-style music. The user is asleep; every other decision below was made
autonomously.

## Assets

- assets/island-tour.webm — the real app driven by `--tour`, recorded with transparency so the island sits on the composition's own wallpaper.
- assets/logo.png — the GitIsle mark (a palm island that branches like git), for the close.
- audio/ — a downloaded, licensed launch-style music track (see Notes).

## Customizations

- No narration: on-screen type carries the story, with the music bed.
- Real footage of the app, never a rebuilt imitation of it.

## Notes

- Decided autonomously (not confirmed by the user): 16:9 rather than the
  route's 1:1 X/LinkedIn default, because the MacBook notch is a wide subject
  and the same file can sit on the landing page and README; about 40 seconds;
  no voice-over; problem → reveal story.
- Preferences were not recorded to memory, because the user did not confirm
  them.
- Example data only (orbit/web, orbit/api); never the user's real repositories.
